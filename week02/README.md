# Week 2 (26.10.21)

EEG를 시뮬레이션으로 만들고, 작은 신경망으로 source 위치를 맞힌 뒤 위치 오차(mm)를 재는 가장 작은 end-to-end 실험임. 목표는 "시뮬레이션 → 학습 → 평가" 한 바퀴를 직접 돌려 보는 것이며, 성능을 주장하려는 것이 아님.

## 실행

```
pip install mne scikit-learn
python week02/mini_e2e.py
```

샘플 데이터(1.6GB)는 필요 없음. 실행 시간은 수 초임.

## 전체 흐름

1. 머리를 구 모양으로 가정하고 10-20 전극 28개를 붙임.
2. 구 안쪽에 10 mm 간격으로 후보 위치 1791개를 깔고, 위치마다 "여기서 쌍극자가 켜지면 전극 28개에 어떻게 보이는가"를 계산함 (leadfield, forward).
3. 후보 위치 하나와 무작위 방향을 골라 센서 신호를 만들고 잡음(SNR 10 dB)을 더함. 학습 20,000개, 테스트 2,000개임.
4. 신호에 average reference를 적용하고 길이를 1로 맞춤. 세기 정보는 버리고 센서 패턴만 사용함.
5. MLP(은닉층 128, 64)가 센서 28개 값을 입력받아 (x, y, z)를 출력하도록 학습시킴.
6. 테스트 2,000개에서 정답과 예측 위치 사이의 거리(mm)를 측정함.

비교 기준은 두 가지임.

- 항상 구 중심이라고 답하기.
- 고전 dipole scan. 후보 1791곳 전부에 쌍극자를 놓아 보고, 센서 신호를 가장 잘 설명하는 위치를 고름.

## 결과

테스트 2,000개, SNR 10 dB, 위치 오차(mm)임.

| 방법 | 평균 | 중앙값 |
|---|---|---|
| 항상 중심이라고 답하기 | 56.8 | 60.0 |
| MLP | 15.4 | 13.8 |
| dipole scan | 13.4 | 14.1 |

MLP는 중심 찍기보다 오차가 훨씬 작음. MLP와 dipole scan은 비슷한 수준임. 한 번 실행한 결과이므로 어느 쪽이 낫다고는 판단하지 않음.

위 숫자는 Python 3.13, numpy 2.2.6, mne 1.13.2, scikit-learn 1.9.1에서 나온 값임. Python 3.14, numpy 1.26.4 환경에서는 MLP 7.3 / dipole scan 45.5로 다르게 나옴. 두 환경 모두 실행 중 numpy 경고(divide by zero, overflow)가 뜨며, 원인은 확인하지 못함.

## 한계

- 구형 머리 모델이라 실제 머리 모양을 반영하지 못함.
- 데이터 생성과 위치 추정에 같은 forward model을 사용함 (inverse crime). 정답 위치가 후보 격자 위에 있어 실제보다 결과가 좋게 나왔을 수 있음.
- source가 점 쌍극자 하나이고 시간에 따른 활동 신호가 없음. 클러스터, 신경질량모델(Jansen-Rit 등)은 사용하지 않음.
- SNR 10 dB 하나, 시드 하나로만 실행함.
- 실제 EEG 데이터는 사용하지 않음.
- 실행 환경에 따라 결과가 달라지며 경고 원인도 확인하지 못함 (위 결과 항목 참고).
