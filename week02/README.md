# Week 2 (26.10.21)

시뮬레이션으로 EEG를 만들고, 작은 신경망으로 source 위치를 맞히게 한 뒤 위치 오차(mm)를 재는 가장 작은 end-to-end입니다.

## 실행

```
pip install mne scikit-learn
python week02/mini_e2e.py
```

샘플 데이터(1.6GB)는 필요 없습니다. 실행 시간은 수 초입니다.

## 코드가 하는 일

| 단계 | 내용 |
|---|---|
| 전극 | 10-20 시스템 28채널 |
| 머리 모델 | 구형 3층 (반지름 95 mm) |
| source 후보 | 구 안쪽 10 mm 간격 격자, 1791개 위치 |
| forward | leadfield G, shape (28, 5373) = 1791 위치 x 3방향 |
| 시뮬레이션 | 위치 1개, 무작위 방향의 쌍극자 하나. y = G_i u + 잡음 (SNR 10 dB) |
| 전처리 | average reference, 크기 정규화 (세기는 버리고 센서 패턴만 사용) |
| 데이터 | 학습 20,000개 / 테스트 2,000개 |
| 모델 | MLP (128, 64): 센서 28개 -> (x, y, z) |
| 평가 | 정답과 예측 위치 사이의 거리 (mm) |
| 비교 기준 | 항상 중심이라고 답하기 / 고전 dipole scan |

## 결과

테스트 2000개, SNR 10 dB, 위치 오차(mm)입니다.

| 방법 | 평균 | 중앙값 |
|---|---|---|
| 항상 중심이라고 답하기 | 56.8 | 60.0 |
| MLP | 15.4 | 13.8 |
| dipole scan | 13.4 | 14.1 |

MLP는 중심 찍기보다 훨씬 낫습니다. MLP와 dipole scan은 비슷한 수준이고, 한 번 실행한 결과라서 어느 쪽이 낫다고 말하기는 어렵습니다. 후보 격자 간격이 10 mm라서 오차가 0에 가까워질 수는 없습니다.

## 한계

- 구형 머리 모델이라 실제 머리 모양을 반영하지 못합니다.
- 시뮬레이션과 위치 추정에 같은 forward model을 씁니다 (inverse crime). 결과가 실제보다 좋게 나왔을 수 있습니다.
- source가 점 쌍극자 하나이고 활동 시간 신호가 없습니다. 클러스터, 신경질량모델(Jansen-Rit 등)은 쓰지 않았습니다.
- SNR 10 dB 하나, 시드 하나로만 돌렸습니다.
- 실제 EEG 데이터는 쓰지 않았습니다.
- 실행 시 numpy 관련 divide by zero, overflow 경고가 뜹니다. 결과는 유한한 값으로 나오지만 원인은 확인하지 못했습니다.

## 참고

연구실 논문(Phee et al., CMPB 2026)은 이 구조를 MRI 기반 BEM 머리 모델, 클러스터 source, 3D CNN + 1D CNN으로 확장한 것입니다. 코드는 https://github.com/pheeeeee/eeg_source_localization 에 있습니다.
