## 어댑터 (adapter.py)

몽타주마다 자기 leadfield로 MNE 역연산자 K를 만들고, 평균 기준으로 바꾼 입력 y에 곱해 7,498곳의 source 지도 x = Ky를 얻는다.
모든 몽타주가 공유하는 PCA 기저 B(256 x 7,498)에 투영해서 256차원 벡터로 만들고 MLP에 넣는다.
채널이 몇 개든 입력 크기가 같아지고, 전극이 어디 붙었는지는 leadfield를 통해 들어간다.
sLORETA 어댑터는 K에 sLORETA 정규화를 곱한 것이다. 입력 벡터는 모두 크기를 1로 맞췄다 (세기 정보 제거, 표현만 비교).
비교 대상인 마스크 방식도 같은 정규화를 적용했다.

학습 두 가지
- C1 (엄격): 학습에 무작위 채널 부분집합(3~64개)만 사용. 이름 있는 몽타주 5종은 처음 보는 몽타주
- C2: 학습 샘플의 절반은 이름 있는 몽타주 5종, 절반은 무작위 부분집합

테스트는 정답 머리(전도도 0.010, 전극 위치 오차 5 mm), 방향 0~30도 무작위, SNR 10 dB(64채널 기준).
새 무작위 부분집합은 학습에 쓰지 않은 20개를 채널 수 구간별로 평가.

## 해석

- 처음 보는 몽타주에서 어댑터가 마스크보다 크게 낫다. 32채널은 21.8 → 12.1 mm, 16채널은 28.5 → 17.9 mm (sLORETA 어댑터). 마스크 방식은 학습에서 본 몽타주에만 강하고(C2에서 32채널 13.2 mm), 모르는 부분집합에서는 급격히 무너진다.
- 64/32/16채널에서는 어댑터가 학습에 이름 있는 몽타주가 있든 없든 비슷하다 (C1과 C2 차이 1 mm 이하, 16채널 sLORETA 어댑터는 17.9 vs 16.9). 몽타주를 외우는 것보다 입력 표현이 차이를 흡수한다는 쪽의 증거이다. 단 이마 몽타주는 예외로, 학습에서 못 본 C1이 C2보다 6~32 mm 나쁘다 (sLORETA 어댑터 이마4 54.6 vs 48.7, MNE 어댑터 이마4 68.4 vs 48.8). 학습 분포 밖의 배치에는 어댑터도 일반화하지 못한다.
- 그러나 몽타주별로 따로 학습한 MLP보다는 여전히 나쁘다: 64채널 9.6 vs 8.5, 32채널 12.1 vs 11.2, 16채널 17.9 vs 16.4 mm. 모델 1개의 대가는 1~1.5 mm 정도.
- sLORETA 정규화 어댑터가 MNE 어댑터보다 대체로 낫지만 차이는 0.5~1.3 mm 수준이고 16채널은 MNE 어댑터가 근소하게 낫다(17.6 vs 17.9). 시드 2개로는 순서를 단정하지 않는다. 이마 2채널 C1에서는 MNE 어댑터가 83.6 mm로 크게 무너졌다.
- 이마 2~4채널은 해결하지 못했다. 학습에서 본 경우(C2)에도 48~51 mm로 항상 중심을 답하는 값(52.5 mm)과 비슷하다. C1에서는 54~84 mm로 그보다 나쁘다. 채널 수 문제를 "해결"했다고 쓰면 안 된다.
- 채널 3~8개 무작위 부분집합은 모든 방법이 43~57 mm이다. 정보량 자체의 한계로 보이나, 이 실험이 한계를 증명하지는 않는다.

## 한계 (읽을 때 주의)

- 머리는 sample 1명이다. 어댑터가 "새 머리"에도 통하는지는 이 실험으로 알 수 없다. 오히려 어댑터는 모델 머리의 leadfield를 쓰므로, 머리가 달라지면 이 이점이 어떻게 변할지 모른다. 교수님 메모의 "리드필드를 입력으로 넣으면 잘 된다"는 이 실험과는 다른 설정이며, 여기서 검증하지 않았다.
- 어댑터의 PCA 기저는 이 머리의 source 지도로 만들었다. 다른 머리에서는 기저를 다시 만들어야 하는지 확인하지 않았다.
- 비교 대상인 sLORETA는 튜닝하지 않았다 (lambda^2 = 1/9, depth weighting 없음).
- 어댑터는 7,498 x k 크기의 역연산자를 몽타주마다 계산한다. 실제 사용에서 전극 위치를 몰라 leadfield를 못 만드는 경우는 다루지 않았다.
- 점 source 1개, 시간 정보 없음. 멀티소스와 시계열(Week 4-2)은 합치지 않았다.
- 시드 2개. 1 mm 안팎의 차이는 해석하지 않는다.

## build_subject_forward.py

피험자 한 명의 FreeSurfer 폴더에서 BEM, source space, 전극 위치로 리드필드 (채널 x source x 3)를 만들어 npz로 저장한다.
sample 피험자 + biosemi64로 (64, 7498, 3) 배열이 만들어지는 것까지 확인했다. 다른 머리에서는 실행해 보지 않았다.
- T1만 있는 MRI(예: IXI)는 FreeSurfer recon-all을 먼저 해야 한다. 이 코드는 하지 않는다.
- MRI-전극 정합(trans)은 인자로 받는다. 피험자마다 만들어야 한다.

3. 리드필드를 입력으로 넣는 모델과 어댑터 비교는 (2) 이후에만 의미가 있음. 피험자 식별 지름길(세미나에서 본 global MRI 벡터 문제) 여부를 hold-out 피험자로 확인
